# Prepared post-closure supplemental workflow

This is source-only preparation while the single native run is live. No trace,
force, command archive, model, runtime or helper is imported or decoded during
preparation. Execution waits for the parent to confirm actual native closure.

The ignored wrapper is `outputs/m8_table_supported/audit_fresh_reset_speed2_v3.py`.
Its first evidence gate requires `run_publication_identity_after.json`. It then
checks original BEFORE1ace, producer9ae1a9f, full9f3617 software proof, exact
74-source/672-test identity and the closed e532 serial-reader declaration,
result and three successful reader execution records. Reader completion remains
separate from the original native outcome.

The old frozen b714 supplemental file remains unchanged. Only its pure
`phase_baseline`, `first_open_contact` and `command_stats` functions are reused
after exact SHA verification. Its old failure-specific `audit` function is never
called. The new wrapper is outcome-neutral and records actual native exit,
original acceptance flags, unexecuted planned phases, all executed OPEN/reset
contact counts, acquisition-row/next-row grasp flags, all-step guarded grip
errors, original pad minima, finite cap statistics and sparse retained tracking
errors. It does not assume a final recontact or a successful slower reset.

Full 5D M/J/Jdot arithmetic, cache lag, original contact-frame signs, source-bound
observer/events, whole-task table shares and strict pad/table gaps are reused
from the preceding official readers. Additional raw summaries keep nominal
formed geometry, loaded interior contacts, native support readiness, capture,
qualified lead and passive resets separate. No duplicate full matrix replay or
new combined software-proof claim is made.

After parent-confirmed closure, the parent first runs the frozen serial wrapper
`audit_closed_reset_speed2_v3.py` using its approved matched interpreter/SDK and
proof archive. Only after its three official records and final identity succeed
is this exact supplementary command authorized:

```sh
PYTHONDONTWRITEBYTECODE=1 python outputs/m8_table_supported/audit_fresh_reset_speed2_v3.py outputs/m8_table_supported/full_reset_speed2_v3 outputs/m8_table_supported/full_reset_speed2_v3_audits --arithmetic-source outputs/m8_table_supported/full_c2_inertia_v2_audits/supplemental_open_reset_contact_audit.py --output outputs/m8_table_supported/full_reset_speed2_v3_audits/supplemental_fresh_reset_speed2_audit.json
```

The output path must be new and outside the immutable native directory. An
absent/exceptional official reader is preserved and stops this selected-array
workflow; it is never replaced with a partial physics qualification.

Before publication, archive the exact supplemental source and reused b714
source, complete any narrowly necessary post-closure execution validation, and
freeze the complete recursive binder after all derivative files are closed.
Binder fields are `closed`, `original_run_relative_path`, `producer_commit`,
`native_child_exit_code`, `original_run_files_sha256` and `audit_files_sha256`.
The first map includes every original relative file; the second includes every
derivative relative file except the binder itself. `closed: true` means closed
evidence, with no success implication. Native report/exit and software proof
remain separate from reader completion and supplemental observations.

Timing: original executed command/current solved force labels are t−dt;
retained command geometry is t−2dt except initial-state special cases; sparse
saved qpos and actual jaw aperture are post-integration t. Pitch residuals are
descriptive for shallow starting turns and do not qualify a full thread lead.
